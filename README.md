# Kosmetik Rose – Website

Next.js-Website für den Schönheitssalon und das Elektroepilationsstudio
Kosmetik Rose (Kaiserstraße 75, 44135 Dortmund), inhaltlich orientiert an
[kosmetik-rose.de](https://www.kosmetik-rose.de/).

## Entwicklung

```bash
npm install
npm run dev
```

Danach [http://localhost:3000](http://localhost:3000) im Browser öffnen.

## Build

```bash
npm run build
npm run start
```

## Struktur

- `src/app` – Seiten (Startseite, `/galerie/frauen`, `/galerie/maenner`, `/impressum`, `/datenschutz`)
- `src/components` – Sektionen der Startseite (Hero, Leistungen, Bewertungen, Kontakt, …)
- `public/images` – Bildmaterial
